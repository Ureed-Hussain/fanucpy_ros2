# Examples

Examples will be added one capability at a time after the connection bringup is
validated on the physical controller. Each capability will have equivalent
Python and C++ examples where ROS 2 supports both client APIs.

Implemented examples:

1. Connection and state inspection through bringup.
2. Guarded Cartesian keyboard teleop (`keyboard_teleop.md`).
3. Controller utilities and allowlisted TP programs
   (`controller_utilities.md`).

Planned next:

1. Joint motion.
2. C++ clients for the shared interfaces.
3. Vision-node migration.
