# Security policy

## Supported version

Security fixes are applied to the latest code on the default branch. Until the
first tagged public release, older snapshots are not supported.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting form when it is available for the
repository. If it is unavailable, open an issue containing only a
non-sensitive summary and ask the maintainer for a private reporting channel.

Never publish robot-controller addresses, credentials, proprietary FANUC
files, workcell network details, or instructions that bypass physical safety
controls. A functional-safety concern is also welcome, but this project is not
a safety-rated control system and must not be used as one.
